# sprite-assets Specification

## Purpose

Загрузка всей графики игры из текстовых файлов `assets/*.txt` того же формата, что и в Python-прототипе, чтобы художник правил одни и те же файлы для обеих версий.

## Requirements

### Requirement: Формат файла спрайтов
Загрузчик SHALL читать текстовые файлы UTF-8, где: пустые строки и строки с `;` игнорируются; до первого спрайта допустимы свойства `ключ: значение`; `[имя]` начинает спрайт; строки спрайта состоят только из `#` (включён) и `.` (выключен). Пробелы по краям строк SHALL игнорироваться.

#### Scenario: Чтение файла интерфейса
- **WHEN** загружается `assets/ui.txt`
- **THEN** доступны все спрайты из файла по именам (`icon_food`, `icon_play`, `icon_sleep`, `icon_clean`, `icon_bag`, `icon_settings`, `item_pill`, `item_syringe`, `mini_*`, `arrow_left`, `arrow_right`, `sick`, `lock`)

#### Scenario: Свойства питомца
- **WHEN** загружается `assets/pets/cat/pet.txt`
- **THEN** получены свойства name=CAT, order=1, birth=basket, а free не задан (платный)

### Requirement: Понятные ошибки в ассетах
При битом файле загрузчик MUST остановить запуск с сообщением, где указаны файл, строка или имя спрайта: строки разной длины, символы кроме `#`/`.`, повтор имени спрайта, строка без `:` до первого спрайта, отсутствующий обязательный спрайт, кадры стадии разного размера, кадр больше 28×28, неизвестное значение birth, нет `adult_normal.txt`, нет ни одного питомца.

#### Scenario: Недопустимый символ
- **WHEN** в строке 12 спрайта файла `world.txt` встречается символ `x`
- **THEN** запуск прерывается с сообщением, содержащим `world.txt:12`

#### Scenario: Нет обязательного кадра
- **WHEN** в `pets/cat/child.txt` нет кадра `[sleep]`
- **THEN** запуск прерывается с сообщением, называющим файл и кадр `sleep`

### Requirement: Питомцы и стадии
Каждая папка в `assets/pets/` SHALL быть видом питомца: ключ — имя папки, name/order/birth/free — из `pet.txt` (по умолчанию name = ключ заглавными, order = 99, birth = basket, free = no). Виды SHALL быть упорядочены по (order, ключ). Каждая стадия (baby, child, adult_good, adult_normal, adult_bad) SHALL содержать кадры idle1, idle2, sad1, sad2, happy, eat1, eat2, sleep одного размера. Если файла стадии нет, SHALL браться первая нарисованная из цепочки: baby → child → adult_normal; child → adult_normal; adult_good/adult_bad → adult_normal.

#### Scenario: Порядок на экране выбора
- **WHEN** загружены пять питомцев из репозитория
- **THEN** первым идёт BLOB (order 0), далее по возрастанию order

#### Scenario: Нет файла стадии
- **WHEN** у вида нет `baby.txt`, но есть `child.txt`
- **THEN** малыш этого вида рисуется кадрами `child`
