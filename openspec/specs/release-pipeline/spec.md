# release-pipeline Specification

## Purpose
Автоматическая проверка и выпуск сборок: каждое слияние в основную ветку превращается в пронумерованный GitHub Release с подписанным APK, который ставится поверх предыдущей версии.

## Requirements

### Requirement: Проверка изменений
На каждый pull request и push в `main` CI SHALL прогонять тесты Godot (`tests/run_tests.gd`); падение тестов MUST помечать проверку как проваленную и не выпускать релиз.

#### Scenario: Сломанный тест в PR
- **WHEN** в pull request падает тест
- **THEN** проверка PR красная, релиз не создаётся

### Requirement: Релиз на каждое слияние в main
На каждый push в `main` с зелёными тестами CI SHALL создавать GitHub Release с новой версией: последний тег вида `vX.Y.Z` с увеличенным на 1 `Z` (нет тегов — `v0.0.1`); если в файле `VERSION` записано `major.minor` больше, чем `X.Y` последнего тега, — `major.minor.0`. Релиз MUST содержать APK `pixelpet-vX.Y.Z.apk`; архивы исходников релиза SHALL соответствовать коммиту релиза.

#### Scenario: Слияние PR
- **WHEN** PR слит в `main`, последний тег `v0.0.2`
- **THEN** появляется релиз и тег `v0.0.3` на коммите слияния, в релизе `pixelpet-v0.0.3.apk` и архивы исходников

### Requirement: Версия приложения
APK SHALL иметь versionName, равный версии релиза без `v`, и versionCode, строго растущий от релиза к релизу.

#### Scenario: Два релиза подряд
- **WHEN** выпущены `v0.0.3`, затем `v0.0.4`
- **THEN** у второго APK versionName `0.0.4` и versionCode больше, чем у первого

### Requirement: Подпись одним ключом
Все релизные APK MUST быть подписаны одним release-ключом из секретов репозитория, чтобы новая версия ставилась поверх старой без потери сохранений. Ключ и пароли MUST не попадать в репозиторий и логи. Без секретов релиз MUST не выпускаться.

#### Scenario: Обновление на телефоне
- **WHEN** на телефоне стоит `v0.0.3` с живым питомцем, ставится `v0.0.4`
- **THEN** установка проходит как обновление, питомец на месте

#### Scenario: Секрет не задан
- **WHEN** секрет с ключом отсутствует
- **THEN** шаг релиза падает с понятной ошибкой, релиз не создаётся
