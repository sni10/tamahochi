## ADDED Requirements

### Requirement: Касания на экранах игры
Каждый экран SHALL при отрисовке задавать тап-зоны рядом с нарисованными элементами; тап MUST сначала искать точное попадание, затем — с запасом 2 пикселя ЖК. Кнопки A/B/C и клавиатура SHALL работать как прежде. Зоны:
- комната: иконка меню — выбрать и сразу выполнить (во время анимации — ничего); после смерти тап по комнате — к выбору питомца;
- выбор питомца: слева от питомца — предыдущий, питомец — выбрать (закрытый не выбирается), справа — следующий; подсказки A ◀, B, ▶ C;
- сумка: слева от предмета — предыдущий предмет, справа — следующий (подменю закрывается); сам предмет: расходник — USE, остальное — как B; строка запаса расходника открывает / закрывает подменю USE / BUY / GET; строка подменю — выбрать и выполнить; мазок листает предметы;
- настройки: строка поля — выбрать поле и выполнить B;
- разрешение уведомлений: тап в любом месте — OK;
- подсказки «A NEXT», «B …», «C BACK» на всех экранах — действие своей кнопки.

#### Scenario: Тап по еде
- **WHEN** сытость 50 и игрок касается иконки еды
- **THEN** еда выбрана, сытость 65, идёт анимация еды

#### Scenario: Тап по шприцу
- **WHEN** в сумке показан SYRINGE, в запасе 1, питомец болен, игрок касается шприца
- **THEN** шприц применён: болезнь снята, шприцев 0, анимация лечения

#### Scenario: Тап по запасу
- **WHEN** в сумке показан SYRINGE и игрок касается строки «X 1»
- **THEN** открыто подменю USE / BUY / GET; тап по BUY в тестовой сборке даёт +5 шприцев

#### Scenario: Листание сумки
- **WHEN** показан PILL и игрок касается зоны слева от предмета
- **THEN** показан предыдущий предмет — PREMIUM (по кругу)
