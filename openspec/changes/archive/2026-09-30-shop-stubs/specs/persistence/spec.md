## MODIFIED Requirements

### Requirement: Три файла в папке пользователя
Игра SHALL хранить в пользовательской папке приложения три JSON-файла: `save.json` (все поля состояния питомца), `settings.json` (quiet_start, quiet_end, calls_enabled, notify_asked, time_speed), `player.json` (pills, syringes, umbrellas, owned_pets, premium). Профиль и настройки MUST переживать смерть питомца. Новые поля SHALL иметь значения по умолчанию, чтобы старые сохранения (в т.ч. прототипа) читались.

#### Scenario: Первый запуск
- **WHEN** файлов нет
- **THEN** открывается экран выбора питомца, настройки 22–08, зов включён, таблеток в запасе 0, шприцев 0, зонтиков 0

#### Scenario: Сохранение без нового поля
- **WHEN** `save.json` записан до появления погоды
- **THEN** он читается, счётчик потери от дождя равен 0

#### Scenario: Профиль без зонтиков
- **WHEN** `player.json` записан до появления зонтиков
- **THEN** он читается, зонтиков 0

#### Scenario: Настройки без переключателя зова
- **WHEN** `settings.json` записан до появления CALLS
- **THEN** он читается, зов включён

#### Scenario: Профиль без запаса таблеток
- **WHEN** `player.json` записан до появления купленных таблеток
- **THEN** он читается, таблеток в запасе 0
