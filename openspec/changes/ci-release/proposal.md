## Why

APK сейчас собирается только вручную на машине разработчика. Нужен автоматический релиз: каждое слияние в `main` даёт проверенную, подписанную сборку, которую можно скачать и поставить на телефон поверх предыдущей.

## What Changes

- GitHub Actions: на pull request и push в `main` — прогон тестов Godot.
- На push в `main` (merge) — релиз: версия = последний тег `v*` с патчем +1, подписанный release-APK, GitHub Release с APK; исходники (zip/tar.gz) GitHub прикладывает к релизу сам.
- Release-keystore создаётся один раз локально (вне репозитория), хранится в GitHub Secrets; все релизы подписаны одним ключом.
- Версия приложения (versionName / versionCode) проставляется из CI.

## Capabilities

### New Capabilities
- `release-pipeline`: автоматическая проверка и выпуск релизов — когда запускается, что проверяет, как нумеруется версия, что лежит в релизе, чем подписан APK.

## Impact

- Новый `.github/workflows/release.yml`.
- `export_presets.cfg`: версия подставляется в CI, в репозитории остаётся заглушка.
- Секреты GitHub: keystore (base64), алиас, пароль. Ключ хранится у владельца — потеря ключа = невозможность обновлять приложение.
- Код игры не меняется.
